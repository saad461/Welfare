# Supabase Setup Instructions

Step 1: Go to https://supabase.com
Step 2: Create new project
Step 3: Go to Settings > API
Step 4: Copy Project URL and anon public key
Step 5: Add to .env.local file
Step 6: Go to SQL Editor
Step 7: Paste contents of schema.sql and run
Step 8: Go to Storage and create buckets
        listed in buckets.md
Step 9: Run npm run convert-images
